# v0.6 求职顾问 Agent

## 当前已完成：v0.6.1 可靠匹配基础

- 将复合 JD 拆为可独立评价的原子要求，并保护括号内技术说明不被错误拆分。
- 区分个人事实、技术能力、工程能力、项目经验和加分经历。
- 同时查询本人确认的结构化档案、SQLite 关键词和 Chroma 向量结果。
- 按结构化档案、简历、项目说明、开发计划和普通文档设置来源质量。
- 低质量规划材料不能单独形成强匹配。
- 区分强匹配、部分匹配、明确未满足、证据不足和证据冲突。
- 由确定性代码计算岗位匹配度、证据完整度、已证实能力强度和求职可行度。
- 分析过程通过 SSE 推送，并支持取消、失败降级、持久化和聊天内报告恢复。

## 评分语义

- **岗位匹配度**：所有要求按权重计算的保守满足程度，证据不足不得分。
- **证据完整度**：已有可靠资料覆盖的要求权重比例，不等于能力高低。
- **已证实能力强度**：只在已有证据范围内观察能力吻合程度，用于内部解释。
- **求职可行度**：综合整体匹配、必备项满足度和证据完整度，防止少量强证据造成虚高。

## 当前已完成：v0.6.2 顾问对话工作流

- 保存当前会话绑定的目标岗位和档案版本。
- 支持在普通聊天中继续询问优势、风险、能力缺口和应聘策略。
- 一个问题可以按需组合多个顾问工具，并保留完整 Agent 步骤。
- 增加独立 Career Agent 工具白名单、循环上限和总超时，并复用服务端取消机制。
- 每次回答前重新验证文档活动版本；个人档案版本变化后要求重新分析 JD。
- JD 报告卡片提供四个快捷追问入口，桌面端和移动端共用会话协议。

## 当前已完成：v0.6.3 求职材料生成

- 生成岗位定制的 30 秒、1 分钟和文字版自我介绍。
- 从可信证据中选择适合岗位的项目亮点。
- 生成面试问题、回答思路和能力补足计划。
- 导出带引用的求职分析报告。

所有材料均从当前会话绑定的 JD 报告生成，生成前重新校验个人档案版本和文档活动版本。聊天快捷入口复用 Career Agent 的独立白名单、步骤上限、超时和取消机制；完整报告通过独立接口导出为 UTF-8 Markdown，并在每个章节标注引用编号。
